1. Что такое физическая память?
Физическая память — это оперативная память компьютера (ОЗУ), которая используется для хранения данных и инструкций, выполняемых процессором. В отличие от внешней памяти (жёсткого диска), она требует постоянного электропитания для сохранения информации.

2. Что такое виртуальное адресное пространство? Что значит, что оно изолированное?
Виртуальное адресное пространство — это совокупность виртуальных адресов, доступных процессу. Оно является логическим представлением памяти, которое транслятор присваивает программе независимо от её фактического расположения в физической памяти.
Изолированность означает, что у каждого процесса есть собственное виртуальное адресное пространство, которое не пересекается с пространствами других процессов, даже если виртуальные адреса совпадают. Это обеспечивает защиту и независимость процессов.

3. Какие бывают адреса?
Символьные имена (метки) — присваиваются программистом при написании кода.

Виртуальные (логические) адреса — вырабатываются транслятором, условные адреса внутри виртуального адресного пространства.

Физические адреса — реальные адреса ячеек оперативной памяти.

4. Что такое свопинг?
Свопинг — это механизм выгрузки (полной или частичной) данных процесса из оперативной памяти на диск (в файл подкачки) при нехватке места и возвращения их обратно, когда память освобождается. Это позволяет выполнять процессы, чей суммарный объём памяти превышает объём ОЗУ.

5. Что такое виртуальная память?
Виртуальная память — это механизм управления памятью, при котором ОС использует диск (файл подкачки) для хранения данных, не помещающихся в оперативную память. Это позволяет каждому процессу работать с виртуальным адресным пространством, которое может превышать физический объём памяти.

6. Какие есть виды алгоритмов распределения памяти? Какие алгоритмы из каждой группы вы знаете?
Все алгоритмы делятся на два класса:

С использованием внешней памяти (свопинг, виртуальная память).
Примеры: страничная память, сегментная память, сегментно-страничная память (в лекциях не описаны детально, но упомянуты).

Без использования внешней памяти.
Примеры:

Распределение памяти фиксированными разделами

Распределение памяти динамическими разделами

Распределение памяти перемещаемыми разделами (со сжатием)

7. Как устроена работа страничной памяти?
При страничной организации виртуальной памяти:

Виртуальное адресное пространство процесса делится на виртуальные страницы фиксированного размера (например, 4 КБ).

Физическая память делится на физические страницы (кадры) того же размера.

Для каждого процесса ОС создаёт таблицу страниц, где для каждой виртуальной страницы указан номер физической страницы (или признак её отсутствия в памяти).

При обращении к памяти виртуальный адрес делится на:

Номер виртуальной страницы (старшие разряды)

Смещение внутри страницы (младшие разряды)

Если страница есть в памяти, её номер заменяется физическим, и формируется физический адрес.

Если страницы нет в памяти, происходит страничное прерывание, и ОС загружает её с диска, возможно выгружая другую страницу.

8. Что такое таблица страниц?
Таблица страниц — это системная структура данных, создаваемая ОС для каждого процесса, которая содержит дескрипторы (записи) для каждой виртуальной страницы процесса.
Каждый дескриптор содержит:

Номер физической страницы (базовый адрес)

Признак присутствия в памяти

Признак модификации (была ли страница изменена)

Признак обращения (бит доступа)

Другие служебные флаги

9. Какая информация содержится в строке таблицы страниц?
В дескрипторе страницы (строке таблицы страниц) содержится:

Номер физической страницы (или её базовый адрес)

Признак присутствия (1 — в памяти, 0 — на диске)

Признак модификации (1 — страница была изменена)

Признак обращения (бит доступа, 1 — было обращение)

Права доступа (чтение/запись/исполнение)

Другие служебные поля (например, адрес страницы на диске)

10. Перечислите области адресного пространства процесса в Windows (от младших к старшим адресам) и поясните их назначения.
В лекции указано, что в Windows NT виртуальное адресное пространство делится на две основные непрерывные части:

Пользовательская часть (например, 2 ГБ) — для кода и данных прикладной программы.

Системная часть (например, 2 ГБ) — для кода и данных ОС.

Также упоминаются:

Куча (heap) — для динамического выделения памяти.

Стек (stack) — для локальных переменных, параметров функций.

Выгружаемый пул (paged pool) — область системной памяти, которая может выгружаться на диск.

Невыгружаемый пул (non-paged pool) — область системной памяти, которая всегда находится в ОЗУ (для критичных модулей ОС).
